# ⏳ Time Flow

Time Flow is a simple, good-looking app that helps you see how your time moves through the day, week, month, and year.

## Tech Stack

- Kotlin
- Jetpack Compose
- Jetpack Glance (home screen widgets)
- Material 3
- Hilt (dependency injection)
- Room (local database)
- Coil (image loading)

## Usage

1. Install the app on your Android device.
2. Open the app to view your day, week, month, and year progress bars.
3. Add tasks and events from the calendar screen.
4. Long-press a day to start a countdown.
5. Pin widgets to your home screen to track progress at a glance.
6. Customize theme, colors, and fonts in Settings.
